# 砚田 · 本地 Markdown 读写器

> 一方砚台，半纸光阴。写下即所得，离线且安心。

**砚田** 是一个**纯本地、零依赖、可离线**的 Markdown 编辑器，整个工具就是**一个单独的 HTML 文件**——双击即用，你的文字只存在你自己的浏览器里，**不会上传到任何服务器**。

它是「文房四宝」创作工具族中的「砚」（③ 笔记 → Markdown）：

`笔生`（① 语音 → 文字）· `墨迹`（② 文字 → 笔记）· `砚田`（③ 笔记 → Markdown）· `纸版`（④ Markdown → 网页）

---

## ✨ 特性

- **纯本地离线**：不联网、不依赖任何第三方库，断网照样用。
- **单文件分发**：整个编辑器就是一个 `.html`，发给朋友双击即开。
- **左写右读**：左侧编辑、右侧实时预览，首行对齐、滚动同步。
- **七套主题 + 自定义**：荣耀蓝 / 摸鱼绿 / 华为红等，护眼到深夜赶稿都舒服。
- **大纲 / 双链 / 反链 / 折叠**：长文结构清晰，笔记之间互相引用。
- **灵感三件套（锤子致敬）**：闪念胶囊、大爆炸、一步——想法不污染当前文档。
- **写作模式**：一键隐藏所有非写作 UI，只剩纸和笔。
- **多种导出**：Markdown / HTML / Word / PDF，公众号发布最后一公里。
- **frontmatter 解析**：兼容内容中台的数据契约。

## 📦 手把手：把砚田开源分享出去（发布教程）

下面是从「本地文件」到「别人能搜到、能 Star、能提 PR」的完整步骤。任选一种平台。

### 方式 A：GitHub（国际开源标准，推荐）

1. 注册 / 登录 [github.com](https://github.com)。
2. 右上角 `+` → **New repository**。
3. 仓库名填 `yanxin`（或 `yanxin-markdown`）；勾选 **Public**；**不要**勾 "Add a README"（我们已有）；**License 选 MIT**（也可以不选，本地 LICENSE 文件已够）。
4. 点 **Create repository**，进入空仓库页。
5. 本地打开终端（PowerShell / Git Bash），进入本文件夹：
   ```bash
   cd "C:/Users/Administrator/Desktop/工作台/砚田"
   git init
   git add .
   git commit -m "首次发布：砚田 v1 开源"
   git branch -M main
   git remote add origin https://github.com/你的用户名/yanxin.git
   git push -u origin main
   ```
6. 刷新 GitHub 页面，砚田就公开了。把地址发给朋友即可。

### 方式 B：Gitee（国内访问快，无需翻墙）

1. 注册 / 登录 [gitee.com](https://gitee.com)。
2. 右上角 `+` → **新建仓库**，填 `yanxin`，选 **公开**，语言选 `HTML`。
3. 创建后，本地同样 `git init` → `add` → `commit` → `remote add origin https://gitee.com/你的用户名/yanxin.git` → `push`。
4. 国内朋友打开 Gitee 链接即可下载。

### 方式 C：最轻量——直接发文件（适合小范围给朋友）

如果你只是想给几个朋友用，**根本不需要 GitHub**：把 `砚田 0831升级版_本地Markdown编辑器.html` 通过微信 / 邮件发过去，对方双击就能用。这就是 MIT 允许的"自由分发"。

> 想让大家"双击 .md 就能用"或"像 App 常驻桌面"，再考虑打包成桌面 exe（Tauri），那是进阶玩法，本仓库暂未提供。
